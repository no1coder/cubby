# Cubby 设计规范

## 设计原则

1. **一眼可辨**：卡片按内容类型呈现（颜色即颜色、代码即代码、图片即图片），不需要读字就能找到目标。
2. **键盘优先**：所有操作都有快捷键，鼠标是补充；任何时刻按 `esc` 都能逐层退出。
3. **行为可预期**：粘贴前明确告知目标应用；破坏性操作可撤销；每个操作都有反馈。
4. **安静克制**：不抢焦点、不打扰；权限问题只在需要时温和提示。

## 视觉规格

所有圆角、字号、面板尺寸都从 `Sources/Cubby/Views/DesignTokens.swift` 取值，禁止写魔法数字。

### 圆角令牌（`Radius`）

| 令牌 | 值 | 用于 |
| --- | --- | --- |
| `panel` | 18（macOS 26）/ 14（更早） | 主面板、预览面板 |
| `card` | 12 | 卡片、面板内提醒横幅、帮助浮层、引导步骤卡、预览中的代码块与色块 |
| `group` | 10 | 设置页分组（与系统 Form 一致）、关于页说明块 |
| `control` | 8 | 搜索框、图标按钮、快捷键录制框、预览中的文件行 / 图片 |
| `thumb` | 6 | 卡片内缩略图、来源图标底板（约 0.225 × 边长） |
| `key` | 5 | 键帽（0.5pt `primary 0.1` 描边） |
| 胶囊 | — | 分类标签、按钮（主 = 强调色，次 = `primary 0.08`）、HUD、类型徽标 |

规则：同一层级的元素圆角必须一致；覆盖在面板上的遮罩按面板圆角裁切，不允许出现直角压在圆角容器上。

### 字号阶梯（`FontSize`）

10（键帽）/ 11（元信息、底栏）/ 12（分类、代码、次级按钮）/ 13（正文）/ 14（搜索）/ 15（颜色值、标题）。

### 动效令牌（`Motion`）

所有时长从 `DesignTokens.swift` 的 `Motion` 取值。

| 令牌 | 值 | 用于 | 减弱动态效果时 |
| --- | --- | --- | --- |
| `panelEntrance` + `entranceOffset` | 0.16s ease-out，下落 8pt | 面板出现（透明度 0→1） | 原地淡入 0.1s，不位移 |
| `fade` | 0.1s | 面板关闭淡出（粘贴、贴图时立即关闭）；卡片悬停；按钮按下 | 不变 |
| `previewFade` | 0.14s | 预览面板淡入 | 改为 0.1s 淡入 |
| `previewResize` | 0.16s ease-out | 预览面板随选中项调整高度 | 直接跳到新高度 |
| `overlayFade` | 0.15s | 帮助浮层淡入淡出、列表滚动到选中项 | 不做动画 |
| `layoutChange` | 0.2s snappy | 提醒横幅与更新横幅出现 / 消失、底栏轻提示切换 | 不做动画 |
| `tabSlide` | 0.22s snappy | 分类胶囊滑动 | 不做动画 |
| `selection` | 0.12s | 卡片选中态切换 | 不变（只变颜色，不位移） |
| `TextPickMetrics.opening*` | 每行 0.16s，错开到总长 ≤ 0.3s，从 0.92 放大 | 拆词卡词块按行依次淡入 | 不做动画 |
| `TextPickMetrics.pressedScale` | 0.985（`fade` 0.1s） | 卡片按下（长按 0.45 秒打开拆词卡） | 不缩放 |

规则：开启系统「减弱动态效果」时，去掉一切位移、缩放与滑动，只保留不超过 0.1s 的淡入淡出或直接切换。SwiftUI 视图通过 `Motion.animation(_:reduceMotion:)` 读取 `accessibilityReduceMotion`（返回 nil 即不做动画）；AppKit 窗口动画读取 `Motion.prefersReducedMotion`；截图覆盖层读取 `OverlayMotion`（见下文「截图覆盖层」）。

## 面板结构

```
┌──────────────────────────────┐
│ 🔍 搜索剪贴板…            ⚙︎ │  搜索框
│ 全部 文本 链接 图片 文件 颜色 收藏│  分类
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ [App] 微信         3分钟前 │ │  卡片：来源 + 时间
│ │ 内容预览（最多 3 行）      │ │
│ │ 86 字符              ⌘1 │ │  元信息 + 快捷键
│ └──────────────────────────┘ │
│ ...                          │
├──────────────────────────────┤
│ 12 项      ↩ 粘贴到「微信」  ? │  底栏：数量 + 目标应用 + 帮助
└──────────────────────────────┘
```

空格预览：在面板旁（优先左侧）弹出 440 宽的预览面板，展示完整内容、元信息与操作；不抢焦点，随选中项实时更新。

拆词卡（⌘B、长按卡片 0.45 秒、右键「拆词」）：详情区的第三种内容，与预览、翻译卡三者互斥，键盘焦点始终留在主面板。预览打开时 ⌘B 切到拆词卡、关闭后回到预览；翻译卡打开时 ⌘B 切到拆词卡；拆词卡打开时空格 / ⌘Y 切到预览、⌘T 切到翻译卡。卡片跟随选中项，换条目时选取清空；不支持的条目（链接、颜色、文件、没有文字的图片）显示状态页，移回来继续。结果按原文拼接（规则见 TEXT-PICK-DESIGN.md P8），粘贴与条目粘贴同一投递段，写入带本应用标记、不入历史。

翻译卡（⌘T，macOS 26 起、翻译服务接线后才有）：与预览共用同一个窗口，二者互斥（空格 / ⌘Y 切到预览，预览里 ⌘T 切到翻译卡，关闭翻译卡时回到打开前的预览）。卡片跟随选中项：已缓存的立即显示，本机引擎立即翻译，大模型要在一条上停留 0.6 秒才发送。译文按段到达，每段以 150–300ms 逐字显现；「对照」悬停一段时原文与译文一起高亮；图片在原图上逐块叠画译文，「对照」为卷帘（2pt 白线、28pt 拖柄，拖过或点过后 ← / → 微调），悬停一块 400ms 显示原文气泡。交互细节与数值以原型 `docs/prototypes/clipboard-translate.html` 为准，接入点见 [CLIP-TRANSLATION-DESIGN.md](CLIP-TRANSLATION-DESIGN.md)。

## 键盘

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` / `⌃P` `⌃N` | 选择 |
| `⌥↑` `⌥↓` / `Home` `End` | 跳到首条 / 末条 |
| `Page Up` `Page Down`（笔记本上为 `fn↑` `fn↓`） | 上移 / 下移 5 条（`PanelCommand.pageSize`，约一屏标准卡片） |
| `↩` | 粘贴（按默认格式） |
| `⇧↩` | 以另一种格式粘贴（默认保留格式时即为纯文本） |
| `⌘↩` | 仅复制，不粘贴 |
| `⌘1`…`⌘9` | 快速粘贴 |
| `空格` | 搜索框为空时切换预览 |
| `⇥` / `⇧⇥` | 切换分类 |
| `⌘P` | 收藏 |
| `⇧⌘P` | 把选中的图片贴到屏幕（与 `⌘P` 成对；非图片条目只发出提示音） |
| `⌘⌫` / `⌘Z` | 删除 / 撤销删除 |
| `⌘O` | 打开链接或文件 |
| `⌘,` | 设置 |
| `⌘Y` | 预览（搜索框不为空时空格用于输入） |
| `⌘T`（或 `⇧⌘T`） | 打开 / 关闭翻译卡（帮助打开时先关帮助；不支持的类型提示音 + 底栏说明） |
| `⌘B` | 打开 / 关闭拆词卡（帮助打开时先关帮助；不支持的条目提示音 + 底栏「这个条目没有可拆分的文字」） |
| 拆词卡打开时 | `↩` / `⇧↩` 粘贴所选、`⌘C` / `⌘↩` 复制所选并留在面板（搜索框里选中了文字时 ⌘C 仍是拷贝）、`⌘A` 全选 / 已全选时清空（仅搜索框为空时）；没有选取时 ↩ / ⌘C 提示音 |
| `⌥↩`（或 ⌥ + 小键盘 Enter） | 翻译后粘贴：卡片行内显示进度，完成后粘贴并以 HUD 注明引擎；失败只在行内给出原因与操作，绝不退回粘贴原文；30 秒总时限 |
| 按住 `⌥` 约 0.3 秒 | 选中卡片淡入为流式译文，松开恢复；此时按 ↩ 粘贴正在显示的译文，按其他键立即取消（⌥↑ / ⌥↓ 保持原义）。翻译卡打开时按住 ⌥ 看原文 |
| 翻译卡打开时 | `↩` / `⌥↩` 粘贴译文（富文本条目按「默认粘贴格式」写 RTF / HTML + 纯文本）、`⇧↩` 纯文本、`⌘C` / `⌘↩` 复制译文并留在面板、`⌘S` 存为新条目、`←` / `→` 切换译文 · 对照 · 原文（搜索框为空时） |
| `esc` | 关闭帮助 → 取消进行中的翻译（翻译卡或 ⌥↩，已到达的部分丢弃）→ 关闭翻译卡 → 关闭拆词卡 → 关闭预览 → 清空搜索 → 关闭面板 |

卡片右键菜单在每一项右侧显示与上表一致的键位（仅作展示，实际按键仍由面板统一处理）；「预览」之后是「拆词 ⌘B」（不支持的条目置灰）；图片卡另有「Pin to Screen」；翻译可用时另有「翻译 ⌘T」「翻译后粘贴 ⌥↩」（不支持的类型置灰）与有缓存时的「复制译文」。帮助浮层（`?`）与右键菜单、上表三处保持一致：总有「⌘B 拆词（或长按卡片）」一行（长按写在这一行里，像双击写在 ↩ 一行：浮层要放进 620pt 的面板），拆词卡打开时再多 ⌘A、⌘C；翻译可用时多 ⌘T、⌥↩、按住 ⌥ 三行，翻译卡打开时再多 ⌘C、⌘S；任一张卡打开时不显示「完整使用说明…」链接。底栏在翻译可用时追加「按住 ⌥ 预览译文」「⌥↩ 翻译后粘贴」（宽度不足时依次让位：⇧↩ → 数量 → 按住 ⌥ → ⌥↩）；翻译卡打开时换成「↩ 粘贴译文到 <App> · ⌘C 复制译文 · ⌘S 存为新条目 · ⇧↩ 纯文本 · esc 关闭」；拆词卡打开时换成「↩ 粘贴所选到 <App> · ⌘C 复制 · ⌘A 全选 · esc 关闭」（放不下时依次隐藏 esc → ⌘A → ⌘C）。

关闭面板后 30 秒内再次呼出，保留上次的分类；搜索词总是清空。

## 可访问性

- **VoiceOver**：整张卡片是一个按钮，朗读「来源 · 标题 · 相对时间」（文件已不存在时在标题后注明；有缓存译文时注明「已翻译」），提示「Press Return to paste, or Space to preview.」；默认动作（VO-空格）为粘贴，其余操作（收藏、预览、拆词、贴到屏幕、翻译、翻译后粘贴、删除）放在「操作」转子里。键帽朗读按键名称（「⇧↩」读作「Shift Return」），分类标签朗读名称与选中状态，图标按钮使用独立的朗读名称而不是悬停提示，纯装饰图标对读屏器隐藏。
- **拆词卡**：词块区是一个「词块」分组，每块是一个按钮元素（朗读块的文字，已选的块值为「已选」，按下切换选取），元素在读屏器第一次查询时才创建；只为有可拆文字的卡片提供「拆词」操作。
- **减弱动态效果**：见「动效令牌」的规则，面板、预览与截图覆盖层都遵循。
- **增强对比度**：卡片描边由 `primary 0.06` 提高到 `0.25`，次要文字提高到 `primary 0.8`（代码卡、颜色卡同理）；提醒横幅的说明文字由 0.75 提高到 0.9，并加 0.5pt 橙色 0.6 描边（更新横幅为强调色描边）。
- **菜单栏图标**：读屏名称随状态变化——「Cubby」「Cubby (paused)」，有新版本时为「Cubby, update available」（暂停时「Cubby (paused), update available」）；蓝点本身对读屏器隐藏。更新横幅与提醒横幅的读屏结构相同（图标隐藏，标题、说明、按钮依次朗读）。
- **对比度底线**：玻璃上的 11pt 说明文字不用 `.secondary`（深色玻璃上约 4.2:1，低于 WCAG AA），改用 `primary 0.75`。

## 文案

- 语气简洁直接，不使用感叹号；动作用动词开头（「粘贴到「微信」」「在访达中显示」）。
- 权限提示说明「为什么需要」与「去哪里开启」，只给一个主按钮。
- 权限用词统一（设置、引导、面板横幅、屏幕录制引导）：能让系统弹出授权询问的按钮叫「Grant Access」（去授权），只能跳转系统设置的按钮叫「Open System Settings」（打开系统设置）；状态为「Allowed / Not allowed」（已授权 / 未授权），与系统设置一致。

## 实现约束

- 面板内不使用 `NSPopover` / sheet 等会成为 key 的子窗口：它们会让面板失焦并被关闭，改用面板内浮层。
- 预览面板不可成为 key window，键盘焦点始终留在主面板的搜索框。翻译卡上的一切键盘操作都经主面板的按键映射（`PanelCommand`，`PanelKeyboard` 另外转发 ⌥ 的 flagsChanged）；鼠标操作遵循非 key 窗口的约束：语言 / 引擎选单用程序化弹出的 `NSMenu`（不用 SwiftUI `Menu`），悬停用 `.activeAlways` 的跟踪区域（不用 `onHover`），卷帘拖动与拆词卡的词块区（点选、拖选、自动滚动、悬停）由接受 first mouse 的 AppKit 视图处理，状态页的按钮不放进 `ScrollView`（其内部容器视图不接受 first mouse）。
- 面板 E2E（`make e2e-panel`，仅调试构建）用合成事件驱动真实窗口：演示条目、命名剪贴板、桩翻译服务，不联网、不读系统剪贴板；定位按钮用 `e2eAnchor`（调试构建记录视图位置，正式构建为空操作）。
- 设置页整体不滚动（`scrollDisabled`）：macOS 26 中工具栏窗口内可滚动的页面会在顶部生成与工具栏等高的「滚动口袋」遮住内容。长列表一律放进页面内的定高列表框。
- 权限提醒可「稍后」收起（本次运行内有效）；更新横幅的「稍后」按版本记在设置里（重启后仍有效，出现更新的版本时再提醒），询问横幅的两个按钮都只问一次。单击卡片为选中、双击或回车为粘贴，与 macOS 列表惯例一致，避免误粘贴。
