# Cubby（小格子）使用指南

Cubby 是一个原生的 macOS 剪贴板历史工具：它记住你复制过的文本、链接、颜色、图片和文件，按一个快捷键就能找回并粘贴。它还能像微信那样截图、标注和贴图，并在 macOS 26 上翻译截图和剪贴板里的内容。所有数据只保存在你的 Mac 上，除非你检查更新或使用自己配置的大模型翻译，Cubby 不会联网。

## 快速开始

这一节帮你装好 Cubby、授予需要的权限，并学会打开面板。

### 安装

- **Homebrew**：在终端运行 `brew install --cask no1coder/tap/cubby`，以后用 `brew upgrade --cask cubby` 升级。
- **安装包**：从 [最新 Release](https://github.com/no1coder/cubby/releases/latest) 下载 DMG，把 Cubby 拖进「应用程序」，再从「应用程序」中打开。

不要直接在磁盘映像或「下载」文件夹里运行 Cubby，否则权限和登录时自动启动可能无法保留。发布版已签名并经过 Apple 公证，首次打开时系统只会确认一次。Cubby 需要 macOS 14 及以上，支持 Apple 芯片与 Intel；翻译功能需要 macOS 26 及以上。Cubby 只在菜单栏显示图标，不占用 Dock。

### 首次启动引导

第一次打开 Cubby 时，会出现「欢迎使用 Cubby」窗口，里面有四张卡片：

1. 「随时呼出」：设置打开面板的快捷键，默认 `⇧⌘V`。默认的 `⇧⌘V` 会代替部分应用中的「粘贴并匹配样式」，你可以随时更改。
2. 「允许读取剪贴板」：macOS 15.4 起，读取剪贴板需要授权，见下文。
3. 「允许直接粘贴」：授予辅助功能权限后，选中条目会直接粘贴到当前应用。
4. 「截图与贴图」：设置截图快捷键，默认 `⇧⌘2`。这里只做介绍，不会申请屏幕录制权限。

两张权限卡片的状态会实时更新。窗口底部可以打开「登录时自动启动」，最后点「开始使用」。之后想再看一遍，可以从菜单栏图标右键菜单中的「设置向导…」重新打开。

### 需要的权限

Cubby 最多用到三项权限，每项只用于一件事，它们的状态都可以在 `设置 › 隐私` 中查看。

**读取剪贴板（macOS 15.4 及以上）**：用于记录你复制的内容。更早的系统上这一项显示「当前系统无需授权」。

1. 先随便复制一点内容，然后在引导窗口或 `设置 › 隐私` 中点「去授权」。剪贴板是空的时候系统不会询问，卡片会提示你先复制内容。
2. 系统弹出询问时，选择「允许粘贴」。
3. 这个询问框没有「始终允许」，状态会变为「当前为「询问」，复制时会反复弹窗」。点变为「打开系统设置」的按钮，在 `系统设置 › 隐私与安全性 › 从其他 App 粘贴` 中把 Cubby 设为「允许」。macOS 15.4 – 15.x 上，这一页叫「粘贴」。
4. 状态显示「已授权」后，复制时就不会再弹出询问。

**辅助功能**：用于在你选中条目后向当前应用发送 `⌘V`，实现直接粘贴。点「去授权」，然后在 `系统设置 › 隐私与安全性 › 辅助功能` 中打开 Cubby。未授权时，选中条目只会复制到剪贴板，面板顶部会提示「暂时只能复制，无法直接粘贴」。

**屏幕录制（仅截图需要）**：第一次截图时才会申请。届时系统会弹出询问，同时 Cubby 显示「截图需要屏幕录制权限」窗口。点「打开系统设置」，在 `系统设置 › 隐私与安全性 › 录屏与系统录音`（macOS 14 为「屏幕录制」）中打开 Cubby。授权后 macOS 可能要求重新打开应用，点窗口中的「退出并重新打开 Cubby」即可。这项权限只在你主动截图时使用，不授权也不影响剪贴板历史。

### 打开面板

在任何应用中按 `⇧⌘V` 打开面板，再按一次关闭；也可以左键点击菜单栏图标。点击面板外部或按 `esc` 也会关闭面板。快捷键和面板出现的位置（「鼠标旁」「菜单栏图标下方」或「屏幕中央」）都在 `设置 › 通用` 中修改。

### 菜单栏图标

左键点击菜单栏图标打开面板；右键点击（或按住 Control 点按）打开菜单：

- 「打开剪贴板」「截图」：右侧以灰字显示对应的快捷键。
- 「暂停记录」：勾选后不再记录新复制的内容，菜单栏图标也会随之变化。
- 「清空历史记录…」：确认后删除全部未收藏的条目，无法撤销。
- 「设置向导…」：重新打开首次启动引导。
- 「检查更新…」「设置…」（`⌘,`）「退出 Cubby」（`⌘Q`）。

需要你处理时，菜单顶部还会出现「允许读取剪贴板…」；开启自动检查更新并发现新版本时，会出现「新版本 x.y.z 可用…」。

## 剪贴板面板

面板是 Cubby 的核心：在这里找到复制过的内容，一键粘贴回你正在使用的应用。

### 卡片与分类

每条记录是一张卡片，外观与内容一致：文本显示前几行，富文本保留 RTF / HTML 格式，代码用等宽字体，HEX 颜色（如 `#FF8800`）直接显示为色块，图片显示缩略图，文件显示名称与路径（文件已被删除或移动时加删除线并注明「文件已不存在」）。卡片上还有来源应用的图标和复制时间，前九张卡片右侧标着 `⌘1` – `⌘9`。再次复制相同的内容时，原条目会移到最前，不会重复出现。

顶部的分类标签依次为「全部」「文本」「链接」「图片」「文件」「颜色」「收藏」。按 `⇥` / `⇧⇥` 切换，也可以直接点击。关闭面板后 30 秒内再次打开，会停在上次的分类；搜索词每次都会清空。

### 搜索

打开面板后直接输入即可搜索，命中的文字会高亮。

- 输入多个关键词时，条目要包含全部关键词。
- 除了内容本身，也能按文件路径和来源应用名搜到。
- 图片（包括截图）可以按图中的文字搜到。文字在本机识别，不会上传；可以在 `设置 › 历史` 中关闭「搜索图片中的文字」。
- 翻译过的条目也能按译文搜到。
- 结果按相关度排序：完整包含搜索词的条目排在最前；只靠图中文字命中的排在正文命中之后；只靠译文命中的排在最后。
- 按 `esc` 或点搜索框右侧的清除按钮清空搜索。

### 预览

按 `空格`（搜索框为空时）或 `⌘Y`，在面板旁打开预览，查看完整内容；再按一次关闭。预览会跟随选中项更新，不会抢走键盘焦点。预览底部显示长度、行数、链接的域名、颜色的不透明度或图片的像素尺寸，并按类型提供「粘贴」「打开」「贴图」等按钮。

### 选择与粘贴

用 `↑` `↓`（或 `⌃P` `⌃N`）选择条目，`⌥↑` `⌥↓`（或 `Home` `End`）跳到第一条或最后一条，`Page Up` `Page Down`（笔记本上为 `fn↑` `fn↓`）一次移动 5 条。单击卡片只是选中。

- `↩` 或双击卡片：粘贴到当前应用。
- `⇧↩`：以另一种格式粘贴。默认格式是「保留原格式」时，`⇧↩` 就是「纯文本粘贴」，反之亦然。默认格式在 `设置 › 通用 › 文本粘贴格式` 中修改。
- `⌘↩`：仅复制到剪贴板，不粘贴。
- `⌘1` – `⌘9`：快速粘贴前九条中的某一条。

底栏会显示粘贴目标：「↩ 粘贴到」加上目标应用的图标和名称。目标是你打开面板前正在使用的应用。发送 `⌘V` 前，Cubby 会确认目标应用仍在前台；如果中途切换了应用，只会复制，并提示「目标应用已切换，已改为仅复制」。

如果没有辅助功能权限，或在 `设置 › 通用 › 选中条目后` 选择了「仅复制到剪贴板」，`↩` 只会复制，底栏显示「↩ 复制」，这时自己按 `⌘V` 粘贴即可。

### 收藏、删除与撤销

- `⌘P`：收藏或取消收藏。收藏的条目出现在「收藏」分类中，不受历史条数上限影响，清空历史时也会保留。
- `⌘⌫`：删除选中的条目，底栏会显示「已删除」和「撤销」。
- `⌘Z`：在提示消失前（约 4 秒）撤销删除，条目回到原位。关闭面板后就不能再撤销了。

### 打开、贴图与拖放

- `⌘O`：打开链接（用默认浏览器）、文件或图片。
- `⇧⌘P`：把选中的图片贴到屏幕中央，成为置顶小窗，用法见「截图」一节的「贴图窗口」。对非图片条目只会发出提示音。
- 拖动卡片到其他应用，可以直接放入文本、图片或文件。

### 右键菜单

右键点按卡片，会列出可用的操作，右侧显示对应的快捷键：

- 「粘贴」「仅复制」「预览」「删除」，以及「收藏」或「取消收藏」。
- 富文本条目另有「粘贴为纯文本」或「粘贴为保留原格式」。
- 链接、文件和图片有「打开」；图片有「贴图」；文件有「在访达中显示」。
- macOS 26 上还有「翻译」「翻译后粘贴」，已翻译的条目另有「复制译文」。不支持翻译的条目，这两项会置灰。

### esc 与快捷键帮助

`esc` 会逐层退出：关闭快捷键帮助 → 取消正在进行的翻译 → 关闭翻译卡或预览 → 清空搜索 → 关闭面板。

点底栏右侧的键盘图标（「快捷键」），面板中会显示全部快捷键和鼠标操作；点空白处或按 `esc` 关闭。这份列表会随状态变化：不能直接粘贴时，`↩` 一行写的是「复制」；翻译可用时，会多出翻译相关的几行。

### 暂停记录

需要复制敏感内容时，可以暂停记录：在菜单栏图标菜单中勾选「暂停记录」，或打开 `设置 › 隐私` 中的「暂停记录」。暂停期间：

- 新复制的内容不会保存，菜单栏图标会变化。
- 面板顶部一直显示「已暂停记录」横幅，点横幅上的「恢复记录」即可恢复。
- 截图照常可用，只是不会存入历史。
- 不会识别新图片中的文字；「存为新条目」和「复制外文时自动翻译」也会暂停。

## 截图

按 `⇧⌘2` 冻结屏幕，选择窗口或区域并标注，然后复制、存储、贴图或提取文字。

### 开始截图

有三种方式：按 `⇧⌘2`（可以在 `设置 › 截图` 中修改或关闭）；在菜单栏图标菜单中选「截图」；或点面板顶部搜索框右侧的相机按钮。

屏幕画面会立即冻结。如果面板开着，它会先隐藏，不会出现在截图里。前三次截图时，屏幕底部会显示操作提示。第一次截图时会申请屏幕录制权限（见「快速开始」）。截图过程中再按一次截图快捷键：还没画标注时会取消截图；画过标注后会被忽略，避免误触丢掉标注。

### 选择窗口

移动指针时，指针下的窗口会高亮，高亮的部分就是将要截取的范围。指针在桌面、菜单栏或 Dock 上时，整块屏幕高亮。

- 单击：选中高亮的窗口或屏幕，之后可以调整和标注。
- `↩` 或 `⌘C`：直接截取高亮的目标并复制。
- 双击窗口：选中并立即完成。
- `⌘A`：选中指针所在的整块屏幕。

窗口重叠时，按 `⇥` 或向下滚动，会逐层高亮后面的窗口，最深一层是整块屏幕；按 `⇧⇥` 或向上滚动返回。这样只露出一角的窗口也能一键选中。窗口上的标签会显示应用名、像素尺寸，重叠时还有「第几层 / 共几层」。

### 纯净窗口截图

指针在窗口上时按一下 `空格`，进入纯净窗口模式：放大镜隐藏，高亮样式改变，标签提示「单击截取 · ⌥ 去阴影 · 空格 退出」。纯净窗口截图会直接复制并存入历史，不进入标注。

- 单击或按 `↩`：只截这一个窗口，即使它被其他窗口挡住也能完整截到，保留透明圆角和阴影。
- 按住 `⌥` 单击：同样截取，但不带阴影。
- 再按 `空格`：退出纯净窗口模式。

### 框选与调整选区

按住鼠标拖出一个区域即可框选。拖动时按住 `⇧` 得到正方形，按住 `⌥` 从起点向四周扩展，按住 `空格` 可以保持大小、平移整个选区。选好之后：

- 拖动 8 个手柄或边缘调整大小（按住 `⇧` 保持正方形），在选区内拖动可以移动它。
- 方向键把选区移动 1 pt，按住 `⇧` 移动 10 pt。选区左上角的尺寸以像素为单位。
- 在选区外拖动会重新框选；右键点按选区会清除它，方便重新框选。两种情况下已画的标注都会保留。
- 选区只能位于一块屏幕内。

### 放大镜与取色

选择窗口、框选和拖动手柄时，指针旁会出现放大镜，逐像素显示指针下的画面，下方是坐标和颜色值。按 `C` 复制放大镜显示的颜色值并结束截图，HEX 颜色会作为颜色卡存入历史。按住 `⇧` 时颜色值改为 RGB 显示，这时按 `C` 复制的也是 RGB。

### 标注

选好区域后，选区下方会出现工具栏。按字母键或点工具栏选择工具：

- `R` 矩形，按住 `⇧` 画正方形。
- `O` 椭圆，按住 `⇧` 画圆。
- `A` 箭头，按住 `⇧` 以 45° 为步长。
- `P` 画笔。
- `H` 荧光笔：重叠处不会加深，底下的文字仍然清晰。
- `M` 马赛克：只模糊截图画面本身。
- `T` 文字：单击放置文本框，支持拼音等输入法。`↩` 换行；按 `esc`、`⌘↩` 或点击文本框外结束输入，空白的文本框会被丢弃。
- `N` 序号：单击放置。删除其中一个后，后面的编号自动补位。

再按同一个字母键或按 `V`，回到指针。选中工具后，工具栏旁会出现样式条：每个工具有三档粗细（文字工具为「小」「中」「大」）和 8 种颜色，马赛克只有粗细。也可以按 `1` – `8` 依次选择红色、橙色、黄色、绿色、蓝色、紫色、黑色、白色，按 `[` / `]` 减细或加粗一档。

有选中的标注时，样式的改动作用于它，否则作用于当前工具。每个工具都会记住你上次用的样式，重启后仍然保留。标注可以画到选区外：显示时保留，导出时裁掉，之后扩大选区就能把它们包进来。

### 修改、撤销与放弃

完成截图之前，标注一直可以修改。在指针模式（`V`）下单击某个标注将其选中，然后可以拖动它、用方向键微调（按住 `⇧` 每次 10 pt）、在样式条上改颜色或粗细，或按 `⌫` 删除。用文字工具单击已有的文字，可以重新编辑。`⌘Z` 撤销、`⇧⌘Z` 重做，拖动一个标注只算一步。

- 还没画标注时，按一次 `esc` 即取消截图；没有选区时右键点按也会取消。
- 画过标注（或已经翻译）后，第一次按 `esc` 只提示「再按一次 Esc 放弃截图」，再按一次才放弃。期间做了其他操作，提示就会失效。
- 在文本框中输入时，`esc` 只结束输入，不会取消截图；输入法选字时按 `esc` 只关闭候选框。

### 完成截图

- **复制**：按 `↩`、`⌘C`、在选区内双击，或点工具栏上的「完成」。截图复制到剪贴板，并以来源「截图」存入历史。前台应用保持不变，可以马上粘贴。
- **存储**：按 `⌘S` 或点「存储」，在存储对话框中选择文件夹和文件名。只存 PNG，默认文件名形如 `Cubby 2026-09-27 01.23.45.png`，对话框会打开上次使用的文件夹。点「取消」会回到截图，选区和标注都还在。存储的截图也会存入历史，但不写入剪贴板。
- **贴图**：按 `⌘P` 或点「贴图」，截图会原位、原尺寸地贴在屏幕上，同时存入历史。
- **提取文字**：按 `⌘T` 或点「提取文字」。Cubby 用 Apple Vision 在本机识别选区中的中英文文字（不包括标注），按阅读顺序复制，并作为文本存入历史。没有文字时提示「没有识别到文字」。

在 `设置 › 截图` 中关闭「每次存储前询问位置」后，`⌘S` 会直接存入「截图存储位置」中的文件夹，不再弹出对话框；同名文件会自动加上编号，文件夹不可用时存到桌面。暂停记录时，以上操作照常可用，只是不会存入历史。

### 贴图窗口

贴图浮在所有窗口之上，可以同时贴多张。

- 拖动可以移动；滚轮或双指捏合以指针为中心缩放（10% – 400%），`⌘0` 恢复原始大小。
- 右键菜单有「拷贝」（`⌘C`）、「存储…」（`⌘S`，总会弹出存储对话框）、「不透明度」（100%、80%、60%、40%）和「关闭」（`⌘W`）。
- 双击或按 `esc` 关闭。贴图出现时不会抢走键盘焦点，先单击它，键盘快捷键才会作用于它。

贴图会出现在下一次截图的画面里。退出 Cubby 后，所有贴图都会消失。历史中的图片也能用 `⇧⌘P` 贴出来，出现在屏幕中央。

## 截图翻译

在 macOS 26 上，按 `⇧⌘T` 可以把选区里的文字原位翻译，译文直接排在原文所在的位置。

### 开始翻译

截图翻译需要 macOS 26 及以上；更早的系统上，工具栏没有「翻译」按钮，`⇧⌘T` 也不起作用。框选区域后，按 `⇧⌘T`，或点工具栏上「提取文字」右侧的「翻译」按钮。在文本框中输入时按 `⇧⌘T`，会先结束输入再翻译。

1. **识别**：Cubby 在本机识别选区中的文字，按段落、列表项和表格单元格分块，翻译条显示「正在识别文字…」。
2. **翻译**：译文逐块流式出现，翻译条显示进度，例如「正在翻译 5/14」。
3. **原位替换**：每块原文被抹去，译文按原来的位置、字号、颜色和对齐方式排好，按钮保持原来的形状。

翻译完成后仍然可以继续标注，标注会画在译文之上。

### 翻译条

翻译条出现在工具栏远离选区的一侧。翻译完成后，它包含：

- **语言选单**：显示「英语 → 简体中文」这样的语言对，点击可以换目标语言。换语言时会沿用已识别的文字重新翻译，并记住这次的选择，下次沿用。与原文相同的语言会置灰。
- **引擎徽标**：笔记本图标表示在本机翻译，云图标表示文字会发送到你配置的服务；悬停可以看到说明。
- **「原文 | 译文」开关**：决定「完成」「存储」「贴图」导出哪个版本。已有译文时，按 `⇧⌘T` 也会切换它。开关在「译文」时，按 `⌘T` 提取文字得到的是译文。
- **「卷帘对比」**：打开后拖动分隔线对比原文与译文。
- **「复制译文」**：按阅读顺序复制全部译文，每块一行，未翻译的块用原文。复制的文字会存入历史（暂停记录时除外），截图保持打开。
- 提示「按住空格看原文」。

### 对比原文的四种方式

- **按住 `空格`**：临时显示原文，松开回到译文。
- **卷帘对比**：分隔线默认在选区中间，左侧是原文，右侧是译文。拖动圆形拖柄移动分隔线；拖过之后可以用 `←` `→` 微调，按住 `⇧` 步长更大。
- **悬停**：指针在某块译文上停留约 0.4 秒，会弹出这一块的原文。
- **「原文 | 译文」开关**：在两个版本之间切换。

只有开关会影响导出的结果；按住空格、卷帘和悬停都只用于查看。

### 撤销与取消

- `⌘Z` 一步撤销整个翻译，`⇧⌘Z` 恢复。换一次目标语言也算一步。
- 识别或翻译进行中，撤销和重做不可用。这时按 `esc` 只取消翻译，回到翻译前的画面，已经到达的译文会丢弃。
- 翻译失败时，按 `esc` 关闭翻译条。翻译完成后要放弃截图，同样需要按两次 `esc`。
- 翻译之后移动或放大选区，译文会固定在屏幕内容上。新选区包含没翻译过的区域时，翻译条提示「选区已变化」，点「重新翻译」即可。

### 哪些文字不翻译、不发送

下面这些文字保持原样，也不会发送给任何翻译引擎：

- 不含字母的内容，例如数字、价格、时间和符号；
- 看起来是代码、文件路径、网址、邮箱或命令行的文字；
- 已经是目标语言的文字；
- 被马赛克遮住的文字；
- 疑似密钥的文字，例如 API Key 和令牌。

想隐藏某些内容时，请在翻译前先打上马赛克。使用大模型时，只发送识别出的文字，截图本身从不上传。

### 翻译失败时

翻译条会显示简短的原因和对应的按钮：

- 「大模型尚未配置」或「API Key 无效或无权限」：点「去设置」，截图会暂时隐藏，并打开 `设置 › 翻译`。关闭设置窗口后截图回来，配置可用时会自动重试。
- 「需要先下载「英语 → 简体中文」语言包」：点「下载语言」，在系统弹出的界面中确认下载，下载完成后自动重试。
- 「无法连接到 …」「请求过于频繁或额度不足」「服务暂时不可用」「返回内容无法识别」：点「重试」。
- 「不支持该语言组合」或「原文已是英语，请选择目标语言」：在语言选单中选择其他目标语言。
- 「未发现可翻译的文字」：选区中没有需要翻译的内容。

只有部分块失败时，已到达的译文会保留，翻译条提示「部分内容未翻译」，点「重试」只重发没完成的部分。

## 剪贴板翻译

在 macOS 26 上，面板里的文本、富文本和图片也能翻译，译文可以直接粘贴。

### 打开翻译卡

在面板中选中一条，按 `⌘T`（或 `⇧⌘T`），也可以在右键菜单中选「翻译」。翻译卡在面板旁打开，再按一次 `⌘T` 关闭。翻译卡有三种视图，点击切换，或在搜索框为空时按 `←` `→` 切换：

- 「译文」：只看译文。
- 「对照」：原文与译文逐段对照，悬停在一段上会同时高亮它的原文。
- 「原文」：只看原文。

译文逐段流式出现。富文本会保留标题、列表、粗体和链接，行内代码不翻译。在翻译卡中按住 `⌥` 可以临时查看原文。

翻译卡打开期间会跟随选中项：切换到其他条目时，翻译过的立即显示；使用系统翻译时立即开始翻译；使用大模型时，要在一条上停留约 0.6 秒才会发送，快速翻过的条目不会被发送，停留期间按 `↩` 会立即发送。预览和翻译卡显示在同一个位置：翻译卡打开时按 `空格` 或 `⌘Y` 切到预览，在预览中按 `⌘T` 切回翻译卡。

### 语言与引擎

翻译卡顶部有这些内容：

- **语言胶囊**：显示检测到的原文语言和目标语言，例如「英语（自动检测）→ 简体中文」。点击可以选择目标语言，选择会被记住，截图翻译也会沿用。原文语言在选单中置灰。
- **按应用记住语言**：语言选单底部有一项「粘贴到 Slack 时总是译为此语言」（显示的是当前粘贴目标应用的名称）。勾选后，以后粘贴到这个应用时总是译为当前的目标语言；再点一次取消。已记住的应用列在 `设置 › 翻译 › 按应用记住的目标语言` 中。
- **对调按钮 `⇄`**：把当前译文译回原文语言，方便检查译文是否准确。结果不会保存，图片不支持对调。
- **引擎徽标**：显示正在使用的引擎。点击可以查看文字的去向，并打开「翻译设置…」。
- **隐私说明**：语言胶囊下方的一行，告诉你内容的去向，例如「本机翻译，内容未离开此 Mac」「已发送到 api.deepseek.com」或「已缓存 · 本次未发送」。

### 翻译卡上的操作

翻译卡打开时，面板中的按键会作用于译文：

- `↩` 或点「粘贴译文」：把译文粘贴到当前应用。富文本条目的译文按默认粘贴格式保留格式。`⌥↩` 效果相同。
- `⇧↩`：以纯文本粘贴译文。
- `⌘C` 或点「复制译文」：复制译文，面板保持打开。`⌘↩` 也是复制译文。
- `⌘S` 或点「存为新条目」：把译文存为一条新记录，来源显示为「译文」。暂停记录时不可用。

翻译还没完成时按 `↩`，按钮会变为「完成后粘贴」，译文完成后自动粘贴。复制或粘贴译文不会新增历史条目，只有「存为新条目」会。粘贴之后会短暂提示所用的引擎，例如「已用系统翻译（本机）翻译并粘贴」。翻译卡底部显示原文语言和长度，以及引擎与耗时，或「已缓存」。

### 翻译并粘贴

不想打开翻译卡时，选中条目后按 `⌥↩`，或在右键菜单中选「翻译后粘贴」，一步完成翻译和粘贴：

- 已有该目标语言的译文时，立即粘贴。
- 否则卡片上显示进度，例如「翻译中 3/12 · esc 取消」，面板保持打开，完成后自动粘贴。
- 失败时，卡片上会用一行文字说明原因，并给出「重试」「去设置」或「下载语言」等按钮。Cubby 绝不会退回去粘贴原文。
- 30 秒内没有完成时，提示「翻译超时 · ⌘T 打开翻译卡」。
- 原文已是目标语言时，提示「原文已是英语 · ⌘T 选择目标语言」之类的信息，不会粘贴。

如果你为当前的粘贴目标应用记住了目标语言，`⌥↩` 会优先使用它。

### 按住 ⌥ 预览译文

在列表中选中一条，按住 `⌥` 约 0.3 秒（期间不按其他键），卡片内容会淡入为译文，松开即恢复。按住期间再按 `↩`（也就是 `⌥↩`），粘贴的就是你看到的译文。按下其他键会立即取消预览，所以 `⌥↑` `⌥↓` 仍然用来跳到第一条和最后一条。使用大模型时，同样要停留满约 0.6 秒才会发送。

### 缓存、「译」角标与搜索

- 译文随条目保存在本机，再次打开时立即显示，不会重复发送。每条最多保存 3 种语言的译文。
- 有译文的卡片会在收藏星标旁显示「译」角标，悬停可以看到翻译过的语言。
- 搜索也会查找译文。只因译文命中的卡片，会显示译文的第一行并高亮关键词。
- 在 `设置 › 翻译` 中打开「在卡片上显示译文」后，所有翻译过的卡片都会显示译文第一行。
- 删除条目时，它的译文一起删除。`设置 › 翻译 › 清除全部译文…` 只删除译文，保留历史。

### 图片条目

历史中的图片（包括截图）也能翻译，效果与截图翻译相同，译文逐块原位替换。

- 翻译卡中的「对照」变为卷帘：拖动分隔线对比；拖过或点过分隔线后，可以用 `←` `→` 微调。
- 悬停在一块译文上约 0.4 秒，会显示这一块的原文；按住 `⌥` 可以查看原图。
- `⌘C` 复制和 `↩` 粘贴的都是翻译后的图片，`⌘S` 把它存为新的图片条目。
- 长边超过 8192 像素或超过 8K 分辨率的图片无法翻译。

### 不支持翻译的内容

链接、文件、颜色和代码片段不翻译，超过约 1 万个字符的文本也无法翻译。对这些条目按 `⌘T` 或 `⌥↩` 只会发出提示音，并在底栏说明原因，例如「代码片段不翻译」「链接不支持翻译」或「文字过长，无法翻译」。

### 疑似密钥

使用大模型时，如果条目看起来含有密钥（API Key、私钥、令牌等），Cubby 不会发送，翻译卡显示「疑似包含密钥，未发送」。确认要翻译时，点「仍然翻译」。这个确认只对这一条、这一次和当前显示的服务有效，Cubby 不会记住。使用系统翻译时，文字不会离开本机，会直接翻译。图片中疑似密钥的文字从不发送，也无法确认发送。

### 复制外文时自动翻译

在 `设置 › 翻译` 中打开「复制外文时自动翻译」（默认关闭）后，你复制外文文本时，Cubby 会在后台自动翻译，结果保存为这一条的译文。打开它时会一并打开「在卡片上显示译文」，方便你在列表中看到结果。

- 只使用本机的系统翻译，从不使用大模型，也不联网。
- 只适用于已下载的语言，从不自动下载语言包。
- 只处理 2 – 2000 个字符的普通文本，不处理链接、代码、颜色、文件、图片和疑似密钥的文字。
- 暂停记录或开启低电量模式时停止。

## 翻译引擎与设置

翻译默认使用免费、离线的系统翻译，你也可以在 `设置 › 翻译` 中接入自己的大模型。

截图翻译与剪贴板翻译共用同一个引擎和同一个目标语言。`设置 › 翻译` 只在 macOS 26 及以上显示。

### 系统翻译（默认）

系统翻译使用 macOS 自带的翻译功能，在本机完成，免费，可以离线使用，文字不会离开你的 Mac。

首次翻译某种语言时，需要先下载语言包。翻译条或翻译卡会提示缺少语言包，点「下载语言」后，Cubby 会请 macOS 弹出系统的下载界面，是否下载由你在系统界面中确认，Cubby 不会替你下载。下载完成后即可离线翻译。已下载的语言在 `系统设置 › 通用 › 语言与地区 › 翻译语言` 中管理，`设置 › 翻译` 中的「管理语言…」按钮可以直接打开那一页。

### 配置大模型

任何兼容 OpenAI Chat Completions 接口的服务都可以接入。预设有 DeepSeek、通义千问、Kimi、智谱 GLM、OpenAI、OpenRouter、Ollama（本机），也可以选「自定义」。

1. 打开 `设置 › 翻译`，在「翻译引擎」中选「大模型」，下方会出现「大模型」一组设置。
2. 在「服务商」中选择一个预设，「Base URL」会自动填好。
3. 选择地域：通义千问、Kimi 和智谱 GLM 有多个接入地址，点地址框右侧的地球图标，选择「中国内地」「国际」等地域。选「自定义」时，自己填写服务地址。地址必须以 `https://` 开头，只有 `localhost` 这类本机地址可以用 `http://`。
4. 在「API Key」一栏粘贴你的 Key，点「保存」。Key 存进 macOS 登录钥匙串，并与当前地址绑定，下方显示「存储在钥匙串中」。之后界面只显示 Key 的最后四位，点「移除」可以删除它。
5. 在「模型」一栏点「刷新」获取模型列表，再从右侧的选单中选择；也可以直接输入模型名称，然后按 `↩`。
6. 点「测试连接」。成功时显示「连接成功」、模型名、耗时和一句示例译文；失败时显示原因。

配置完整后，截图翻译和剪贴板翻译都会使用这个大模型，翻译条和翻译卡上会显示它的名称。想换回来，在「翻译引擎」中选「系统翻译」即可；大模型的配置和 Key 会保留，下次再选「大模型」就能直接使用。如果选了「大模型」但还没配置完整，翻译时会提示「大模型尚未配置」，点「去设置」即可回到这里。

### 使用本机的 Ollama

1. 在 Mac 上安装并运行 Ollama，并下载一个模型。
2. 在「服务商」中选「Ollama（本机）」，地址会填为 `http://localhost:11434/v1`。地址在本机时不需要 API Key，这一栏会隐藏。
3. 点「刷新」选择已下载的模型，或直接输入模型名称，然后点「测试连接」。

文字只发送到本机的 Ollama，不会离开这台 Mac。

### 目标语言

`设置 › 翻译 › 翻译为` 决定译成哪种语言：

- 「自动（跟随系统）」（默认）：译为系统首选语言中第一个与原文不同的语言；原文已是系统语言时译为英文。如果系统语言是英语、原文也是英语，Cubby 会请你在翻译条或翻译卡上选择目标语言。
- 选定某种语言：总是译为这种语言。可选的语言有简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español、Português、Italiano、Русский、Tiếng Việt、ไทย、Bahasa Indonesia 和 العربية。

在截图的翻译条或翻译卡的语言选单中换语言，也会改写这里的设置；想恢复自动，在这里选回「自动（跟随系统）」。剪贴板翻译还会优先采用「按应用记住的目标语言」：粘贴到某个应用时，总是译为你为它记住的语言，原文已是这种语言时除外。

### 剪贴板相关设置

`设置 › 翻译` 底部的「剪贴板」一组包括：

- 「复制外文时自动翻译」：见「剪贴板翻译」一节。
- 「在卡片上显示译文」：在翻译过的卡片上显示译文第一行。
- 「按应用记住的目标语言」：列出你在翻译卡语言选单中记住的应用和语言。点某个应用右侧的移除按钮（「不再记住此应用的语言」）即可删除。
- 「已保存的译文」：点「清除全部译文…」并确认，会删除历史条目上保存的全部译文，历史本身不受影响。

### 费用

系统翻译和本机的 Ollama 不收费。使用云端大模型时，费用由服务商按你自己账户的计费规则收取，Cubby 不收费，也不经手你的账户。较长的文本会分成几次请求发送。你可以在服务商的控制台查看用量；额度不足时，翻译会提示「请求过于频繁或额度不足」。

## 设置

从菜单栏图标菜单中的「设置…」、面板顶部的齿轮按钮或面板中的 `⌘,` 打开设置窗口。

### 通用

- **语言**：「界面语言」可选「跟随系统」（默认）、「English」或「简体中文」。切换后点「立即重新打开」，Cubby 会重新打开并回到设置。这里只改变 Cubby 自身的菜单和文字，翻译的「自动」目标语言仍按系统语言。它和 `系统设置 › 通用 › 语言与地区 › 应用程序` 中为 Cubby 设置的语言是同一项，改哪边都可以。
- **快捷键与面板**：「呼出快捷键」，点击后按下新的组合（需包含 `⌘`、`⌥` 或 `⌃`，`F1` – `F12` 可以单独使用）；「面板位置」可选「鼠标旁」「菜单栏图标下方」「屏幕中央」。
- **粘贴**：「选中条目后」可选「直接粘贴到当前应用」或「仅复制到剪贴板」；「文本粘贴格式」可选「保留原格式」或「纯文本」，`⇧↩` 使用另一种。
- **启动与更新**：「登录时自动启动」；「每周自动检查更新」，默认关闭，只读取 GitHub 上的发布信息。

### 历史

- 「最多保留」：50 – 2000 条，默认 500 条。超出后自动删除最早的条目，收藏不计入上限。
- 「搜索图片中的文字」：默认开启。关闭后会删除全部已识别的文字。
- 「当前条目」「占用空间」和「数据目录」，点「在访达中显示」可以打开数据所在的文件夹。
- 「清空历史记录」：点「清空…」并确认，收藏的条目会保留。

### 截图

- **快捷键**：「截图快捷键」可以修改，也可以点「关闭」，关闭后只能从菜单栏和面板截图。呼出快捷键和截图快捷键不能相同。
- **存储**：「截图存储位置」默认「与系统截图相同」，可以「选择文件夹…」或「恢复默认」；「每次存储前询问位置」默认开启。

### 翻译（macOS 26）

这一页包括「翻译引擎」（「系统翻译」或「大模型」）、「翻译为」、系统翻译的「语言包」或大模型的「服务商」「Base URL」「API Key」「模型」「测试连接」，以及底部的「剪贴板」一组。详见「翻译引擎与设置」一节。

### 隐私

- **权限**：「读取剪贴板」「辅助功能」「屏幕录制」三项的状态与按钮。能让系统直接询问时按钮是「去授权」，需要到系统设置中修改时是「打开系统设置」。直接粘贴失效时，这里会显示修复步骤。
- 「暂停记录」：暂停期间复制的内容不会保存。
- 「不记录疑似密钥和令牌」：默认开启，从终端或浏览器复制的 API Key、私钥、JWT 等也能识别。标记为机密或临时的内容（例如密码管理器复制的密码）则始终不会被记录。
- **忽略的应用**：在这些应用中复制的内容不会被记录。点「添加应用…」添加，点应用右侧的移除按钮（「不再忽略」）移除。默认已包含常见的密码管理器。

### 关于

- 版本号。
- 「检查更新」：只在你点击时访问 GitHub。有新版本时点「前往下载」；通过 Homebrew 安装的，运行 `brew upgrade --cask cubby`。
- 「复制诊断信息」：复制版本、系统和权限状态，便于反馈问题，不包含任何剪贴板内容。

## 隐私与数据

Cubby 的数据只保存在你的 Mac 上，只有你要求时才会联网。

### 保存在本机的内容

- 历史保存在 `~/Library/Application Support/Cubby`：`history.json` 保存文本、链接、颜色、富文本格式、文件路径（不复制文件本身）、来源应用、复制时间、收藏标记、译文和图片中识别出的文字；`Images` 文件夹保存图片和翻译后的图片。
- 这个文件夹只有你的 macOS 用户能访问，并且排除在 Time Machine 备份之外。Cubby 不额外加密数据，建议开启 FileVault。
- 设置保存在 `~/Library/Preferences/io.github.no1coder.Cubby.plist`，其中不含剪贴板内容和 API Key。
- API Key 保存在登录钥匙串中，名称为 `io.github.no1coder.Cubby.translation`，不会写入设置、历史或日志。
- 截图时冻结的画面只在内存中，取消截图不留任何痕迹。贴图在退出 Cubby 后消失。

### 不会记录的内容

- 密码管理器等应用标记为机密、临时或自动生成的内容。
- 「忽略的应用」中的应用里复制的内容。
- 疑似 API Key、私钥、JWT 的文本（默认开启，可以关闭）。这是尽力而为的检测，无法识别所有格式。
- 暂停记录期间复制的内容。

### 联网规则

Cubby 不会主动联网，没有统计、遥测和崩溃上报。只有下面两种情况会发出请求：

- **检查更新**：点「检查更新」，或开启每周自动检查后，访问 `api.github.com` 读取最新版本信息，不发送任何剪贴板内容。
- **使用大模型翻译**：仅当引擎为大模型，并且你翻译截图或条目时（包括翻译卡跟随选中项时停留约 0.6 秒、按住 `⌥` 预览），以及你在设置中点「刷新」或「测试连接」时。请求只发往你配置的地址，远程地址必须使用 HTTPS，Cubby 也不会跟随重定向到其他主机，所以 Key 不会被转发到别处。

使用大模型时发送的内容：

- 截图：选区中识别出的文字，以及目标语言、检测到的原文语言、模型名和 API Key。
- 剪贴板条目：这一条的文字；图片则只发送其中识别出的文字。富文本中的链接地址会换成占位符，行内代码和代码块不发送。
- 「测试连接」只发送单词 Hello；「刷新」只发送 API Key。

从不发送：图片本身、被马赛克遮住的文字、未经你确认的疑似密钥、图片中的疑似密钥，以及历史中的其他条目。系统翻译、复制外文时自动翻译、图片文字识别和提取文字都在本机完成，不联网。用 `⌘O` 打开链接时交给默认浏览器处理，Cubby 不会抓取链接预览。

### 删除数据

- **删除一条**：选中后按 `⌘⌫`。
- **清空历史**：菜单栏图标菜单中的「清空历史记录…」，或 `设置 › 历史`。收藏会保留。
- **删除全部译文**：`设置 › 翻译 › 清除全部译文…`。
- **删除图片中识别出的文字**：关闭 `设置 › 历史 › 搜索图片中的文字`。
- **删除 API Key**：在 `设置 › 翻译` 中点「移除」。
- **彻底删除**：通过 Homebrew 安装的，运行 `brew uninstall --zap --cask cubby`。其他情况请先退出 Cubby，删除 `/Applications/Cubby.app` 和 `~/Library/Application Support/Cubby`，再在终端运行 `defaults delete io.github.no1coder.Cubby` 和 `tccutil reset All io.github.no1coder.Cubby`。如果保存过 API Key，请先在设置中移除，或在「钥匙串访问」中删除名为 `io.github.no1coder.Cubby.translation` 的条目。

完整说明见 [隐私说明 PRIVACY.md](https://github.com/no1coder/cubby/blob/main/PRIVACY.md)，其中有简体中文版本。

## 常见问题

遇到问题时，先看看下面的解决办法。

### 选中条目后只复制、不粘贴

- 确认 `设置 › 通用 › 选中条目后` 是「直接粘贴到当前应用」，并且 `设置 › 隐私` 中「辅助功能」显示「已授权」。
- 更新 Cubby、从源码重新构建，或换装签名不同的版本后，系统设置里的开关可能仍显示开启，实际已经失效。这时面板会显示「直接粘贴已失效」，点「修复…」按提示操作：在 `系统设置 › 隐私与安全性 › 辅助功能` 中选中 Cubby，点「−」移除，再回到 Cubby 点「重新授权」，在弹出的列表中打开 Cubby。
- 仍然无效时，在终端运行 `tccutil reset Accessibility io.github.no1coder.Cubby`，然后重新授权。

### 截图没有反应

- 第一次截图前需要屏幕录制权限。在「截图需要屏幕录制权限」窗口中点「打开系统设置」，打开 Cubby。授权后仍然无法截图时，点这个窗口中的「退出并重新打开 Cubby」。
- 截图快捷键可能已关闭或与其他应用冲突，请在 `设置 › 截图` 中查看。你也可以从菜单栏图标菜单或面板的相机按钮截图。
- 提示「无法截取屏幕，请查看系统权限弹窗」时，看看是否有系统弹窗在等你确认。

### 每次复制都弹出粘贴询问

这是 macOS 15.4 起的剪贴板隐私保护。系统询问框只有「允许粘贴」和「不允许粘贴」，没有「始终允许」。在 `系统设置 › 隐私与安全性 › 从其他 App 粘贴`（macOS 15.4 – 15.x 为「粘贴」）中把 Cubby 设为「允许」即可。菜单栏图标菜单中的「允许读取剪贴板…」和面板横幅上的「打开系统设置」都会直接打开这一页。如果列表中还没有 Cubby，先复制任意内容，再到 `设置 › 隐私` 中点「去授权」。

### 找不到翻译按钮

翻译需要 macOS 26 或更高版本。在 macOS 14 和 15 上，截图工具栏没有「翻译」按钮，面板中的 `⌘T` 和 `⌥↩` 只会发出提示音，设置窗口中也没有「翻译」页。

### 提示需要下载语言包

系统翻译第一次使用某种语言时需要下载语言包。点「下载语言」，在系统弹出的界面中确认下载；也可以提前在 `系统设置 › 通用 › 语言与地区 › 翻译语言` 中下载。「复制外文时自动翻译」不会下载语言包，没有下载的语言会被跳过。

### API Key 无效，或提示 Key 属于其他地址

- 「API Key 无效或无权限」或「DeepSeek 拒绝了 API Key」：Key 可能已失效、填错，或没有这个模型的权限。到 `设置 › 翻译` 中点「移除」，重新粘贴后点「保存」，再点「测试连接」。
- 「API Key 是为 A 保存的，请为 B 重新填写。」：Key 与保存时的地址绑定。改了 Base URL 或地域之后，旧的 Key 不会发往新地址，请为新地址重新填写。
- 「请求过于频繁或额度不足」：稍后重试，或检查服务商账户的余额。

### 系统询问是否允许访问钥匙串

Cubby 读取保存的 API Key 时，macOS 可能会询问是否允许 Cubby 使用钥匙串中的条目，常见于从源码重新构建或换装签名不同的版本之后。选择「允许」或「始终允许」即可。如果选择了拒绝，设置中会显示「无法访问钥匙串，已保存的 API Key 暂时无法使用。」，点「重试」可以再试一次。

### 按快捷键面板不出现

- 确认菜单栏中有 Cubby 的图标，Cubby 不在 Dock 中显示。左键点击图标也能打开面板。
- 快捷键被其他应用占用时，Cubby 会提示并恢复为之前的快捷键。到 `设置 › 通用` 中录制一个新的组合。
- 面板会出现在「面板位置」设置的位置；使用多台显示器时，出现在指针所在的显示器上。

### 反馈问题

请在 [GitHub Issues](https://github.com/no1coder/cubby/issues/new/choose) 提交问题。附上 `设置 › 关于` 中「复制诊断信息」的内容会很有帮助，其中不含任何剪贴板内容。请不要在截图或描述中包含真实的密钥或其他敏感内容。安全问题请按 [SECURITY.md](https://github.com/no1coder/cubby/blob/main/SECURITY.md) 私下报告。

- `⌘P` — 收藏 / 取消收藏

- `↩` 或 `⌥↩` — 粘贴译文

- `⌘C` 或 `⌘↩` — 复制译文
- `⌘S` — 存为新条目
