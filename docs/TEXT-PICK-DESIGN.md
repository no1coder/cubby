# 拆词（Pick Words）设计

长文本条目只想用其中一部分时，把文字拆成一个个词块，点选或拖选后粘贴 / 复制所选部分（类似锤子「大爆炸」）。
原型：`docs/prototypes/text-pick.html`（2026-10-03 用户确认，「按推荐做」）。

## 1. 决策

| # | 决策 |
| --- | --- |
| P1 | 名称：中文「拆词」，英文「Pick Words」（不借用别家的「大爆炸 / Big Bang」） |
| P2 | 入口：`⌘B`（再按关闭）、在卡片上长按 0.45 秒（移动不超过 4pt）、右键菜单「拆词 ⌘B」、VoiceOver 操作转子「拆词」 |
| P3 | 位置：详情区的第三种内容（与空格预览、翻译卡共用同一窗口，三者互斥）；键盘焦点始终留在主面板 |
| P4 | 支持的条目：文本（含富文本、代码，按纯文本拆）；已识别出文字的图片（拆 `recognizedText`）。链接、颜色、文件与没有文字的图片不支持：提示音 + 底栏提示「这个条目没有可拆分的文字」；拆词卡打开时选中项移到不支持的条目，卡片显示状态页（同一句话），移回来继续 |
| P5 | 拆分：系统分词（`NLTokenizer(.word)`，中日文按词）；先用 `NSDataDetector` 把网址、邮箱、电话号码保护成一整块（实测分词器会把它们拆碎）；地址、日期不合并（范围太大，用户常只要其中一段）。空白不成块；换行另起一行，空行多留段距；标点单独成块（小一号、颜色淡） |
| P6 | 长度上限：只拆前 20,000 个字符（与预览一致），超出时副标题注明「只显示前 20,000 个字符」 |
| P7 | 选取：单击切换一块；按住拖过一串连选（起点未选中 = 加选，起点已选中 = 取消），拖到边缘自动滚动；⇧单击从上次点击处连选；`⌘A` 全选（已全选时清空） |
| P8 | 结果：相邻选中的块（中间只有空白）按原文连成一段，保留原有空格与换行；段与段之间：原文间隔含换行 → 换行；两侧字符都是中日韩文字 → 直接相连；否则 → 一个空格 |
| P9 | 输出：`↩`（及 ⇧↩、底栏「粘贴」）把结果粘贴到目标应用（与条目粘贴同一投递段：提升原条目 → 隐藏面板 → ⌘V）；`⌘C`、`⌘↩`、底栏「复制」只复制并留在面板，底栏轻提示「已复制」 |
| P10 | 历史：结果带本应用的写入标记，**不记录为新条目**（与复制译文一致，避免历史里堆满片段） |
| P11 | 不在第一版：中文按词 / 按字切换、双击选整句、键盘逐词移动选取 |

## 2. 交互

- **打开**：`⌘B` 对选中项打开；预览打开时 `⌘B` 切到拆词卡，关闭后回到预览；翻译卡打开时 `⌘B` 切到拆词卡。拆词卡打开时空格 / `⌘Y` 切到预览、`⌘T` 切到翻译卡。
- **跟随**：拆词卡跟随选中项（同翻译卡），换条目时选取清空。
- **esc 顺序**：帮助 → 进行中的翻译 → 翻译卡 → 拆词卡 → 预览 → 清空搜索 → 关闭面板。
- **按键**（拆词卡打开时）：`↩` / `⇧↩` 粘贴所选；`⌘C`、`⌘↩` 复制所选（搜索框里选中了文字时 ⌘C 仍是拷贝）；`⌘A` 全选（仅搜索框为空时，否则留给搜索框）；`⌘B` / esc 关闭。没有选取时 ↩ / ⌘C 提示音。
- **长按**：按下后卡片轻微缩小（0.985），满 0.45 秒打开拆词卡；移动超过 4pt 取消（交给拖出）；不影响单击选中、双击粘贴。减弱动态效果时不缩放。
- **打开动画**：词块按行依次淡入并从 0.92 放大到 1，总时长不超过 0.3 秒；减弱动态效果时不做动画。

## 3. 视觉

拆词卡宽 440（详情区），高度按内容（最小 236，最大与主面板等高，超出滚动）。

| 区 | 规格 |
| --- | --- |
| 头 56 | 来源图标 20pt · 标题「拆词」13pt semibold · 副标题 11pt 次要色「42 个词 · 点选或拖过来选取」 · 右侧文字按钮「全选」 |
| 词块区 | 内边距 12 × 14；块 13pt、内边距 3 × 7、圆角 6、横距 4、行距 6；底色 `primary 0.07`，悬停 `0.13`；选中 = 强调色底 + 白字；标点 12pt、内边距 3 × 4、次要色；网址 / 邮箱 / 电话未选中时文字为强调色；空行多留 8pt |
| 结果条 | 有选取时出现：11pt 内边距 7 × 10、圆角 8、底色 `primary 0.05`；「」包住结果，最多 2 行，中间省略；右侧字数 |
| 底栏 36 | 左：「已选 5 个词 · 23 个字符」（无选取时「⌘A 全选」）；右：次按钮「复制」、主按钮「粘贴」（无选取时置灰） |
| 主面板底栏 | 拆词卡打开时换成「↩ 粘贴所选到 <App> · ⌘C 复制 · ⌘A 全选 · esc 关闭」，放不下时依次隐藏 esc → ⌘A → ⌘C |

## 4. 实现

| 层 | 内容 |
| --- | --- |
| CubbyCore `TextPick/` | `TextPickDocument`（分词结果，纯值）、`TextPickTokenizer`（分词 + 实体保护 + 上限）、`TextPickSelection`（不可变选取：切换、区间加 / 减、全选）、`TextPickResult`（P8 拼接）、`TextPickLayout`（给定块宽与容器宽排出每块位置与总高）、`TextPickSource`（条目 → 可拆文字或不支持） |
| Cubby `TextPick/` | `TextPickController`（@Observable：当前条目、文档、选取、跟随）、`TextPickCardView`（SwiftUI 头 / 结果条 / 底栏）、`TextPickCanvasView`（AppKit 自绘词块：接受 first mouse、拖选、自动滚动、悬停、无障碍元素） |
| 接线 | `DetailPane.textPick`；`PanelCommand.pickWords`（⌘B）与卡片打开时的 `⌘A` / `⌘C`；`PanelViewModel+TextPick`；`PreviewPanelController` 高度；`PanelController` 粘贴 / 复制；卡片长按、右键菜单、读屏操作、帮助浮层、底栏提示 |
| 测试 | CubbyCore 单元测试（分词、实体、上限、选取、拼接、排版、来源）；`make e2e-panel` 场景（⌘B 打开 / 关闭、点选、拖选、⌘A、⌘C 写入命名剪贴板且不入历史、↩ 粘贴、不支持的条目、跟随选中项、长按、右键菜单、esc 顺序） |
