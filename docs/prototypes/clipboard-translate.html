模拟状态

前三种自动切到大模型，最后一种切到系统翻译。点错误里的「去设置 / 重试 / 下载语言」即视为已修复。

卡片与自动翻译

自动翻译从不自动上云：即使引擎选了大模型，也只在本机用系统翻译。打开它时会一并打开「在卡片上显示译文」。

设计要点

  • 两种节奏：⌘T 打开翻译卡片（看、对照、再决定）；⌥↩ 直接翻译并粘贴；按住 ⌥ 先在卡片里预览译文，松开即恢复，避免「盲贴」。
  • 隐私默认：系统翻译在本机完成；大模型只在你主动触发时发送，发什么在这里逐字可见；疑似密钥默认拦截，需明确点「仍然翻译」。复制时自动翻译只用系统翻译。
  • 译文是条目的附属数据：翻过的卡片带「译」标记，再开秒出（已缓存），搜索也能命中译文；要独立保存时再 ⌘S 存为新条目。
  • 结构不丢：富文本按段编号翻译再按编号放回，标题、列表、粗体、链接保留；行内代码用占位符替换，不发送也不翻译。图片沿用截图翻译的「抹除 + 重排」。
  • 卡片跟随选中项：系统翻译立即翻；大模型要在一条上停留 0.6 秒才发送，快速翻过的条目不会被发出去。

试一试

  1. 选中 Mail 那封邮件，按 ⌃T（或 ⌘T）看流式译文，切到「对照」把鼠标放到段落上。
  2. esc 关闭，在搜索框输入「合并」：英文邮件靠译文被搜到。
  3. 选中 Safari 那条富文本，按住 ⌥ 约 0.3 秒预览译文，不松手再按 ↩ 粘贴。
  4. 选中「预览」的截图，⌘T 看图片翻译；切到「对照」拖动卷帘，按住 ⌥ 看原文。
  5. 引擎换成大模型，选中「终端」那条再 ⌘T：疑似密钥被拦截。
