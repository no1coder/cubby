机制

  1. 识别：Vision 在冻结帧（不含标注）上识别文字行，全程本机。
  2. 分段：按行距、缩进、字号把行合并成块；代码、纯数字、已是目标语言、被马赛克覆盖的块直接跳过。
  3. 编号翻译：每块一行 JSON {"id","text"}，只发文字不发图片；引擎逐行返回同样格式。
  4. 按编号放回：只认 id，不认顺序；缺行的块保留原文，多出的行丢弃。
  5. 抹除并排版：用采样背景色盖住原文行，在同一框内按原对齐、由行高推出的字号排版；放不下先向同色空白扩展，再缩字（≥75%），最后省略；复杂背景改用半透明底板。译文层在标注之下。
